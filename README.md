# 飞书侧边栏签名插件

这是根据 `signature-service` 后端接口重写的飞书多维表格侧边栏前端。

## 后端地址

默认连接：

```text
https://liupanqing.asia
```

## 功能

- 读取当前多维表格和字段列表
- 选择需要展示给签字人的字段
- 选择签名链接、签字状态、签名截图链接字段
- 调用服务器创建配置和签名任务
- 为当前记录、手动选择的记录或当前视图可见记录生成签名链接
- 将签名链接和待签字状态写回飞书表格

## 使用

```bash
npm install
npm run build
```

构建完成后，将 `dist` 目录按飞书插件要求上传。

## 说明

页面中填写的“多维表格授权码”会传给后端，用于后端读取记录、下载附件、写回签名状态。授权码应由多维表格管理员/所有者在飞书侧边栏插件中获取。

## 1.0.42 最终审核交付说明

本包为飞书客服审核 / GitHub 源码交付包，包含源码、构建产物和插件元信息：

- `src/`：插件源码
- `dist/`：已构建产物，入口为 `dist/index.html`
- `config.json`：飞书多维表格侧边栏插件配置
- `meta.json`：插件名称、版本、描述和主页信息
- `package.json` / `package-lock.json`：依赖和构建脚本

本版本保持默认连接后端：

```text
https://liupanqing.asia
```

最终功能范围：

- 生成签字链接并写回多维表格。
- 维护签字状态、签字图片链接和图片预览增强。
- 支持多签字流程、角色字段绑定和角色防串写。
- 支持签字人可见字段排序。
- 支持服务端统一授权、授权详情展示控制和无 Key 首次打开展示策略。
- 修复跨表 authCode 复用导致的初始化失败。
- 修复保存时重渲染导致新 Key 丢失或写入错误流程。
- 保留真实空 Key / 无效 Key 的撤权安全机制。
